GatePinger privacy policy

Last updated: 21 October 2026

GatePinger is an Android app that keeps your phone's public IP address allow-listed on a Gatekeeper server that you or someone you trust runs, so you can keep reaching self-hosted services when your phone changes networks. The developer of GatePinger runs no server for the app and receives no data from it.

What the app sends, and to whom

GatePinger talks only to the Gatekeeper server you enroll with (the address in your enrollment link or that you type in) and, if one is configured, to an access-check address chosen by that server's operator. Before you confirm an enrollment, it fetches only the invite's details from the server (no token). It sends:

  • An invite code, once, when you enroll.
  • A device token: a random value generated on your phone at enrollment, which identifies this phone to that server on every request.
  • Your phone's public IP address, which any server sees when it is contacted. Keeping it allow-listed is the purpose of the app; the server records it with an expiry time.

Like any app that connects to a server, requests also carry standard technical information such as the app's user agent. The access check sends no token, but the address it contacts sees your phone's public IP address, as every server does.

What the server does with this information is decided by whoever operates it. GatePinger does not send anything to the developer, to analytics or advertising services, or to anyone else.

What is stored on your phone

The server address, the device token, the enrollment details the server returned (device ID, user name, allowed apps) and the optional access-check address are stored in the app's encrypted storage, which is never included in device backups. Recent status (last IP seen, grant expiry) is stored in the app's private storage and may be included in your own Android backup.

Permissions

  • Internet / network state: to contact your server and notice network changes.
  • Foreground service and notifications: a persistent notification shows that the IP guard is running; you can stop it by unenrolling.
  • Run at startup: to resume after a reboot.
  • Battery optimization exemption (optional): so updates aren't delayed for long while the phone sleeps.

GatePinger does not use location, contacts, the camera, the microphone or advertising IDs.

Deleting your data

Tap Unenroll in the app: it asks the server to disable this phone and remove its IP addresses, then deletes everything the app stored on the phone. The server may keep a record of the disabled device and its activity history according to its operator's policy; ask the operator to delete it. Uninstalling the app deletes its local data; in that case also ask the server's operator to remove the device.

Children

GatePinger is a technical tool for people who use a self-hosted server. It is not directed at children.
