# Privacy Policy for ParagPinger

**Last Updated:** January 2025

## Introduction

ParagPinger ("the App") is developed by idomp. This Privacy Policy explains how the App collects, uses, and protects your information.

## Information We Collect

### Network Information
- **Wi-Fi network names (SSIDs):** Used to identify your home networks for the network detection feature
- **Network connectivity status:** Used to monitor connection state and perform ping operations

### Location Information
- **Approximate and precise location:** Required by Android to access Wi-Fi network information. This data is used solely to identify Wi-Fi networks and is not stored, transmitted, or shared.

## How We Use Information

The App uses collected information exclusively for:
- Detecting when you are connected to designated home networks
- Performing network ping operations to monitor connectivity
- Sending local notifications about network status

## Data Storage

- All data is stored **locally on your device only**
- No data is transmitted to external servers
- No data is shared with third parties
- No personal information is collected or stored

## Permissions Explained

| Permission | Purpose |
|------------|---------|
| Internet | Perform ping operations |
| Access Network State | Monitor network connectivity |
| Access Wi-Fi State | Identify connected Wi-Fi networks |
| Location (Coarse/Fine) | Required by Android to read Wi-Fi SSID |
| Foreground Service | Run network monitoring in background |
| Boot Completed | Restore monitoring after device restart |
| Post Notifications | Display network status alerts |
| Battery Optimization | Ensure reliable background operation |

## Data Security

Since all data remains on your device and is never transmitted, your information is protected by your device's security measures.

## Children's Privacy

The App does not knowingly collect information from children under 13.

We may update this Privacy Policy. Changes will be noted by updating the "Last Updated" date.
